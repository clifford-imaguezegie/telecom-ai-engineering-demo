# TEAD AI — Release Notes Archive

This directory retains the historical technical release notes for the public
read-only recorded investigation demo. References to past builds and their
previous limitations are historical, not claims about the latest deployed UI.

**Current UI line:** V1.7.5 RC2.2 (UX-01 terminology and glossary).
**Latest independently scored build:** RC2.1, 4.265/5 (85.3%).
Formal V1 closeout was not unconditional. See the [current project README](../../README.md).
